# Entrega — Design System Black Friday Condor 2026

**Empieza por `GUIA_VISUAL.html`**, abre ese archivo en tu navegador después de descomprimir este ZIP. Es una guía visual independiente, responsive y con ilustraciones reutilizadas de los materiales compartidos.

- `DESIGN_SYSTEM.md`: especificación completa, alcance, componentes, contratos y criterios de aceptación.
- `design-tokens.json`: tokens estructurados, propuestos (no valores oficiales de marca).
- `design-tokens.css`: variables CSS neutrales compatibles con proyectos Tailwind v3 o v4; no importarlas en producción sin validación previa.
- `GUIA_VISUAL.html`: prototipo del **sistema**, no un reemplazo ni modificación de la página real.
- `assets/`: copias sin cambios de las imágenes originales usadas como referencia y de las cuatro ilustraciones extraídas del paquete Astro aprobado.

## Reglas

No se ha editado el repositorio, ni las imágenes aprobadas del hero, premios, banner blanco, Condor Premia o GDB. No se han cambiado los contenidos comerciales del sitio.
